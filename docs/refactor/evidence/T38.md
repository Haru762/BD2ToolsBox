## 3. 明确未完成（不勾 DONE 的原因）

- **旧 `licenses/` 目录未退役**：原先的理由是「`aboutlibraries.json` 不内嵌许可全文，
  全文由库内置 SPDX 映射运行时解析」——**该结论在 T53 被实测推翻**：字段名是
  `licenses[<spdxId>].content`（不是 `licenseContent`），SPDX 全文确实内嵌
  （Apache-2.0 10,279 字符等，见 [license-inventory.md](../license-inventory.md) §3 的更正）。
  不过 `licenses/` 里的 `ReDustX` / `UnityPy` / `astc-encoder` / `texture2ddecoder` /
  `pixijs` 是**自定义/非 SPDX**条目，`aboutlibraries.json` 里没有它们的 `content`，
  且它们同时服务 GPL 源码分发的许可义务，因此本轮**仍不删除**。
- **引用未全部清理**：`THIRD-PARTY-NOTICES.md`、`repacker/json_to_skel.py` 仍指向
  `licenses/`；`assets/spine-viewer/js/pixi.min.js` 内 vendored 注释含
  `opensource.org/licenses/mit-license`（vendored 字节，不改）。
- **arm64 设备未跑**：`LicensesScreenTest` 只在 x86_64 跑；arm64 真机已掉线。
- **未做独立审查**。
- 计划还要求「把目录删除与构建产物核验绑定」（release 里确实有元数据）—— 本轮验证了
  release APK 内含离线清单（T37 §2），但删除动作本身未执行。
