## 1. 本轮做了什么

### 1.1 攻略正文（核心）

- 新增 `feature/guides/render/GuideHtmlRenderer.kt`（**纯函数，JVM 可测**）：
  - 缓存里的正文 HTML **写死浅色配色**（`color:#222`、`#ccc` 边框、`#fef…` 卡片底），
    深色主题下直接塞进 WebView 就是「深色页面里的白底正文 / 透明文字」；
  - `render(rawHtml, dark)` 在**加载时**注入一层 `<style id="bd2-theme-override">`：
    **旧缓存不用删**，主题在渲染时套用；**不改 Wiki 内容**（只追加 style，正文结构、
    阵容数据、动画协议都不动）；
  - **幂等**：重复渲染按 id 替换，不会叠加多份；
  - 注入位置：`</head>` 之前 → 有 `<head>` 无闭合 → `<html>` 之后补 head → 都没有则前置；
  - 深色覆盖范围：`body`/`a`/`hr`/`td,th`/`.gktable td`/`.hl`/`.fold`/`.mention`/
    `.array-card`/`.battle`/`.tabs .tl`/`.tabs .tr:checked + .tl`/`.tabs .tp`/`.tp-e`/
    `blockquote`/`code,pre`，并声明 `color-scheme: dark`。
- `ui/screens/GuideScreen.kt`：`GuideArticleViewer` 按 `colorScheme.background.luminance()`
  判断明暗，`loadDataWithBaseURL` 改为加载 `GuideHtmlRenderer.render(html, dark)`。
  base URL 仍是 `https://www.gamekee.com/`，站内跳转与图片相对协议解析不变。

### 1.2 Spine 预览

- `assets/spine-viewer/css/main.css`：新增 `html[data-theme="light"]` 一整套浅色变量与
  `html[data-theme="dark"]` 的 `color-scheme`；默认（未标注）保持原深色观感。
  **只换配色变量**，不动控件结构、动画协议或 pixi-spine 的获取/分发策略。
- `assets/spine-viewer/preview_renderer.js`：`DOMContentLoaded` 时读 `?theme=`，
  在渲染前把 `data-theme` 落到 `<html>`（避免深色页面闪一下浅色底）。
- `SpinePreviewActivity.kt`：`loadPreview` 追加 `&theme=dark|light`（按 `uiMode` 判断）；
  `showMessage` 的底色/字色也跟随当前主题（原来恒为深色）。
