## 2. 口径

- 每个类别的 `compressedBytes` = ZIP `compress_size` 之和（**在 APK 里真正占的字节**）；
  `uncompressedBytes` 只作参考；MiB = 1024×1024。
- `containerOverhead` = APK 文件大小 − 所有条目 `compress_size` 之和
  （local header / data descriptor / central directory / EOCD）。
- **脚本自校验**：分类字节 + 开销 == APK 文件大小，不等即写入 `invariantProblems`。
- 分类：`dex` / `androidResources` / `chaquopy`（含 `.imy`）/ `native` / `other`。
