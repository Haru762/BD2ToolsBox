## 3. 测试发现并修复的真实缺陷

`--expected-abi` 首轮把 x86_64 包判为失败，报
`foreign-imy-name token=x86 @ assets/chaquopy/stdlib-x86_64.imy` ——
我的 ABI token 判定用的是**子串**包含，`x86` 会命中 `x86_64`。已改为词边界匹配
（`(?<![a-z0-9_])token(?![a-z0-9_])`，与 `ApkSelector` 同一规则）并加了 3 个回归用例。
这是审计工具的缺陷，不是包的问题；修好后两个包都 exit 0。
