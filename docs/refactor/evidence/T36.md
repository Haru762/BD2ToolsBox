# T36 证据：删除 App 的 Gson 使用与过渡保留规则

- 日期：2026-10-11（Asia/Shanghai）。
- 基点：`e38f09e`（T35 的 Gamekee 迁移之后，`refactor/android-architecture`）。
- 状态：**IMPLEMENTED_NOT_VERIFIED**。Gson 依赖与使用已全部删除、JVM 全绿、release/R8 构建通过；真实设备上的 release `json-migration` smoke 未跑，不勾 T36 DONE。
- 前置：T35。

## 1. 本轮做了什么

- **删除 Gson 依赖**：`app/build.gradle.kts` 去掉 `implementation(libs.gson)`；
  `gradle/libs.versions.toml` 去掉 `gson` 版本与库条目（`release-probe` 未使用）。
- **迁移最后 3 个测试文件**（T35 要求「测试自身的 Gson 读取也要迁移」）：
  - `core/storage/JournalRecoveryFactsTest`：原始 JSON 输入与编辑改用 kotlinx
    （不可变 `JsonObject` → `edit`/`editFacts`/`editRecord` 复制式编辑）；
  - `core/storage/ModSnapshotStoreTest`：键名契约改为直接序列化看键、解析改 kotlinx；
  - `data/repository/BundleBackupRepositoryTest`：sidecar 键集与改名键证伪改 kotlinx。
  （`GamekeeBattleV2RendererTest` 已在 T35 的 Gamekee 增量里迁移。）
- **清理 proguard 过渡规则**：删除 `-keep class com.google.gson.reflect.TypeToken`、
  `-keep class * extends com.google.gson.reflect.TypeToken`、`-keepattributes Signature`、
  `-keepattributes RuntimeVisibleAnnotations`。保留的字段 keep 作为**磁盘格式纵深**
  （kotlinx 序列化器由编译器生成、直接引用属性，磁盘键名来自 `@SerialName` 字符串常量，
  不再依赖反射字段名）。
