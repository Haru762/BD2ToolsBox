### 新依赖成本与冗余清理分开

本轮**没有**为减包引入任何新依赖。`kotlinx-serialization`（T35）与 AboutLibraries
（T37）是更早的架构/许可改动，其成本只体现在 `dex`/`androidResources` 的**绝对值**里，
**不计入**上面的差额，也没有拿来抵消收益。

### 历史「约 11.809 MiB 候选内容池」不是净节省

候选池各项彼此重叠（另一套 ABI 的 Chaquopy 归档与桌面 FMOD 都落在 `chaquopy` 类别里），
本节每一项都是**实际构建出的 A/B 差额**。不把候选池当净节省。
**pyc**（构建机 3.11 vs 目标 3.8，本就不生成）与**压缩/对齐**（T15/T51 的兼容性要求）
都明确**没有**计入收益。

## 4. 安装占用与基本启动/内存（x86_64，MuMu API 32，实测）

| 指标 | 优化前 | 优化后 |
|---|---:|---:|
| 设备上 `base.apk` 字节 | 35,048,281 | **22,833,231**（−12,215,050） |
| `du -sk` | 34,228 KB | **22,300 KB** |
| 冷启动 TotalTime | 367 ms（1 次） | **346 / 347 / 349 ms**（3 次） |
| `TOTAL PSS` | 205,151 KB | **201,918 KB** |
| `TOTAL RSS` | 308,928 KB | **305,676 KB** |
| `logcat -b crash` | — | 空 |

方法：`adb install -r` 两个包分别安装后 `pm path` + `stat`/`du` 读实际落盘大小；
`am force-stop` + `am start -W` 取 TotalTime；`dumpsys meminfo` 取 PSS/RSS。
`extractNativeLibs=false`（minSdk 29+ 默认）下 native 不解出，安装占用 ≈ APK 大小。
**单机单次抽样，只用于确认没有明显退化**，不作性能结论。

## 5. 功能零损失边界（本轮确认的不变项）

- **支持 ABI 不变**：仍只有 `arm64-v8a` / `x86_64` 两个包；`--expected-abi` 两包 exit 0。
- **没有删功能**：只剔除桌面平台 FMOD（Android 无加载路径）；`AndroidPythonStagingTest`
  4/4、`NativeEngineSmokeTest` 9/9 通过（T50）。
- **离线能力不变**：许可全文仍在 `res/raw/aboutlibraries.json`（T53）。
- **运行时获取策略不变**：pixi-spine 仍按原策略首次预览时取回，未改为首次下载核心组件。
- **没有体验代价换数字**：未做 native 重压缩、未删 JNI 符号、未关代码收缩。
