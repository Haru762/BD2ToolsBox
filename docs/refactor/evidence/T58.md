## 3. 发现并修掉的问题

1. **浅/深截图完全相同** → 查明 `theme_mode` 默认 `LIGHT`（正确行为），采集脚本改为
   直接改 App 偏好；并加「同一次采集内截图不得重复」的守卫，任何一维没生效都会被拦下。
2. **release 包 `run-as` 不可用**（`package not debuggable`）→ 改用 `su`；
   **不用 debug 包代替**（那会让截图与交付产物脱钩）。
3. **方向维度本机测不了**（MuMu 固定横屏）→ 脚本一度按计划把请求竖屏的图写成
   `portrait-*.png`，等于把「没拍到」记成「拍到了」。已从计划里去掉方向，
   限制如实写进 `index.json` 的 `limitations`。
4. **核对器缺字段就崩**（`KeyError: fontScale`）→ 改为容错读取，并把「索引缺字段」
   本身记为问题（不默默用默认值掩盖）。
5. **`ThemeContractTest` 用的是朴素亮度**（非 WCAG 相对亮度）→ 新测试实现规范公式，
   并加反向守卫防止被改回去。
