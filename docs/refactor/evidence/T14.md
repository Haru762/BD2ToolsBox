## 3. 发现并修复的回归：Chaquopy 16 改了 bootstrap 扩展的文件名

升级前后两个 release APK 的 `assets/chaquopy/` 对比（`local/t14/after/wheel-compare.txt`）：

- 15.0.1：`bootstrap-native/<abi>/zlib.so`、`_struct.so` 等 11 个
- 16.1.0：`bootstrap-native/<abi>/zlib.cpython-38.so`、`_struct.cpython-38.so` 等 11 个

`PythonRuntime.ensureStarted` 在启动解释器之前会打开 `bootstrap-native/$abi/zlib.so`，用来在打包不一致时尽早失败。不修的话，升级后的包在两个 ABI 上都会在这一步抛 `FileNotFoundException`，Python 永远起不来。**仅靠构建、JVM 单测和宿主 Python 回归都发现不了这个问题**（它们都通过了）。

- 修复前（红）：`audit_native_abi.py` 对两个 ABI 都报 `bootstrap-native/<abi>/zlib.so missing`，exit 1（`local/t14/after/abi-audit-*-pre.json`）；它的证伪测试 8 条中 2 条失败。
- 修复后（绿）：见 §5、§6。release dex 里只剩字符串 `zlib.cpython-38.so`，旧的 `/zlib.so` 字面量已消失。
- 全仓 grep 过 `zlib.so`/`_struct.so`/`math.so`/`bootstrap-native/*.so`，再没有其他硬编码。
