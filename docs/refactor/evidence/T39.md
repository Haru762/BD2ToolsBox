## 1. 本轮做了什么

- `ui/theme/AppThemes.kt`：
  - 新增 `darkColorSchemeFor(theme)`：七套预设各自的深色方案（只覆盖
    primary/secondary/tertiary 系与 background/surface；error 系沿用 M3 默认）；
  - 新增 **`appColorScheme(theme: AppTheme, dark: Boolean, dynamicScheme: ColorScheme? = null): ColorScheme`**
    —— 计划要求的可独立测试入口，**不接收壁纸透明度**；动态取色优先；返回前强制
    `surface`/`background` alpha = 1。
- `ui/theme/Theme.kt`：`BD2ModManagerTheme` 新增 `themeMode: ThemeMode`（LIGHT/DARK/SYSTEM）；
  SYSTEM 用 `isSystemInDarkTheme()`；Android 12+ 动态取色按明暗分别用
  `dynamicLightColorScheme`/`dynamicDarkColorScheme`；状态栏/导航栏图标随明暗切换
  （`isAppearanceLight*Bars = !dark`）。
- `MainActivity`：收集 `viewModel.themeMode` 并传入主题。
- 新增 `ThemeContractTest`（8）。
