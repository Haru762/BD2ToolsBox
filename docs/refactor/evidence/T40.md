- **不再用全局透明展示壁纸**：`BD2ModManagerTheme` 删除 `transparentBackground` 参数与
  `background/surface → Color.Transparent` 的 copy；`appColorScheme` 保证语义面色 alpha=1
  （T39 已建立）。壁纸**不修改全局 ColorScheme**。
- 新增 `ui/components/AppScreenSurface.kt`：文字密集区域的不透明内容面
  （取 `colorScheme.background` 且强制 alpha=1）。
- `MainActivity`：
  - 根 `Scaffold(containerColor = Color.Transparent)` —— 壁纸背景层在下方可见
    （页头/留白等无底色区域）；
  - 内容区改用 `AppScreenSurface`（不透明），列表/正文不再让图片穿过。
- `WallpaperBackdrop` 更新 KDoc：它是**独立背景层**，遮罩仍取 `surfaceContainerLowest`
  （始终不透明、最接近 background）；读取失败/超大图/权限撤销仍安全回退。
