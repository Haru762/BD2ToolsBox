## 1. 本轮做了什么

- **接入 AboutLibraries 13.1.0**（T13 兼容探针已验证的组合）：
  - `gradle/libs.versions.toml`：`aboutLibraries = "13.1.0"`、
    `aboutlibraries-compose-m3` 库、`aboutlibraries-android` 插件；
  - `app/build.gradle.kts`：插件 alias + `implementation(libs.aboutlibraries.compose.m3)`。
- **生成绑定到 variant**（不是手工跑一次）：插件提供
  `:app:prepareLibraryDefinitionsDebug` / `:app:prepareLibraryDefinitionsRelease`，
  合并进 `app/build/generated/aboutLibraries/<variant>/res/raw/aboutlibraries.json`，
  随 APK 分发供设置页离线读取。
- **非 Maven 组件自定义定义**：`config/aboutlibraries/libraries/` 下 19 个 JSON
  （Python 12、原生 5、JS 2），字段含 `uniqueId`/`version`/`developers`/`licenses`/`website`；
  `collect { configPath.set(file("../config/aboutlibraries")); fetchRemoteLicense = false }`
  保证离线可复现。
- **文档**：新增 `docs/refactor/license-inventory.md`（自动收集 + 非 Maven 组件 +
  许可全文位置 + 已知缺口）；`THIRD-PARTY-NOTICES.md` 去掉 Gson、补
  kotlinx.serialization / AboutLibraries，并指向清单与自定义定义。
